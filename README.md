Nova AI Chat App

An AI-powered chat application built using HTML, CSS, and JavaScript.
This project allows users to ask questions and receive AI-generated responses similar to Google Gemini using the OpenRouter API.

---

🚀 Features

- AI-generated responses
- Clean and responsive UI
- Real-time chat interaction
- OpenRouter API integration
- Simple frontend-based project
- Easy to use interface

---

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- OpenRouter API

---

⚙️ Setup Instructions

1. Clone the Reposito

https://github.com/mansishukla8850-spec/Nova-AI-chat-app.git

2. Open Project Folder

cd ai-chat-app


3. Add Your OpenRouter API Key

Open "script.js" and replace:

const API_KEY = "YOUR_API_KEY";

with your actual OpenRouter API key.

---

▶️ Run the Project

Simply open "index.html" in your browser.

---

💡 How It Works

1. User enters a question
2. The app sends the request to OpenRouter API
3. AI generates a response
4. Response is displayed in the chat interface
